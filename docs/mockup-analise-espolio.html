Regras da política

texto exibido na etapa de classificação

Implantação → base Preventivo. Exclusão pelas regras 1 a 5.

  1. Vouch + anterior → Excluir.
  2. Sem Vouch + anterior recorrente (3+) → Preventivo.
  3. Sem Vouch (sem anterior ou pontual) → Preventivo.
  4. Só Vouch + BI positivo. 3 ou mais → Excluir; menos de 3 → Preventivo.
  5. Só Vouch + BI negativo. Preventivo só se vigência < 6 meses e menos de 3 cobranças; senão Excluir.

Acompanhamento → base Reanálise. 3 ou mais taxas no Vouch → Excluir; abaixo de 3 permanece em Reanálise. Item 5.5: faltando insumo, fica no status-base com pendência registrada.
